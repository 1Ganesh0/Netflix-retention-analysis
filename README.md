# Retention & Engagement Analytics for Gen-Z OTT Users

## Overview

This project explores retention and engagement behavior within a simulated Gen-Z OTT ecosystem using product analytics techniques.

The analysis combines OTT content metadata, synthetic user interaction modeling, and engagement KPI tracking to investigate how viewing behavior, binge patterns, and platform interactions influence user engagement and retention.

The project was developed using Python in Google Colab and structured as a product-oriented analytics case study inspired by real-world OTT platform challenges.

---

# Business Problem

Gen-Z audiences increasingly consume short-form, algorithm-driven content across platforms such as YouTube Shorts and Instagram Reels. Despite increasing investments in premium content, OTT platforms continue facing challenges in sustaining long-term engagement and retention.

This project investigates engagement patterns, binge behavior, and retention indicators using simulated OTT user behavior data.

# Key Insights

- Simulated Gen-Z users demonstrated consistent weekly engagement behavior.
- Binge-oriented viewing patterns contributed significantly to overall watch time.
- Mobile-first users represented the dominant consumption segment.
- Users with shorter viewing sessions exhibited elevated churn tendencies.
- Engagement analytics highlighted the importance of personalization and recommendation systems in OTT ecosystems.
